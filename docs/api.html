مستندات وب‌سرویس سراف

فشرده‌سازی، تغییر اندازه و تبدیل تصاویر به WebP و AVIF روی سرورهای سراف — با یک درخواست ساده.

BASE https://seraf.ir/api/v1

معرفی

ورودیJPEG · PNG · WebP · GIF · AVIF
خروجیoriginal · jpeg · png · webp · avif
موتورImagick / GD

همهٔ پاسخ‌ها JSON با کدگذاری UTF-8 هستند، مگر وقتی خود فایل تصویر را درخواست کنید.

// success
{ "ok": true,  "data": { ... } }
// error
{ "ok": false, "error": { "code": "...", "message": "..." } }

شروع سریع

  1. در پنل سراف با کد پیامکی یا نام کاربری و رمز وارد شوید.
  2. کیف پول را شارژ کنید یا یک پلن بخرید.
  3. از بخش «کلیدهای API» یک کلید بسازید (srf_…) — فقط یک‌بار نمایش داده می‌شود.
  4. اولین درخواست را بفرستید:
curl -X POST https://seraf.ir/api/v1/optimize \
  -H "Authorization: Bearer srf_YOUR_KEY" \
  -F "image=@photo.jpg" -F "format=webp" -F "quality=80"

احراز هویت

کلید را در یکی از هدرهای زیر ارسال کنید:

Authorization: Bearer srf_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
X-API-Key: srf_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
هدر اختیاریکاربرد
X-Seraf-Clientنوع کلاینت، مثلاً wordpress/1.0.0 (در گزارش مصرف نمایش داده می‌شود)
X-Seraf-Siteدامنهٔ سایت شما؛ برای کلیدهای محدود به دامنه لازم است
کلید را هرگز در JavaScript سمت مرورگر قرار ندهید. کلید لو رفته را از پنل باطل کنید. سراف فقط هش SHA-256 کلید را نگه می‌دارد.

هزینه و پرداخت

  • واحد پول تومان است و هر تصویر بهینه‌شده یک واحد مصرف حساب می‌شود.
  • ابتدا سهمیهٔ پلنی که زودتر منقضی می‌شود و سپس «پرداخت به ازای مصرف» از کیف پول.
  • اگر تصویر کوچک‌تر نشود (skipped) یا پردازش خطا بدهد، هزینه برگشت داده می‌شود.
  • بدون سهمیه و موجودی: 402 insufficient_balance.

آخرین پردازش‌ها (حداکثر ۲۰۰ ردیف). فیلدها: id، client، site، filename، in_format، out_format، in_bytes، out_bytes، charged، charge_source، status، error، created_at.

کلید لازم/v1/optimizePOST

بهینه‌سازی یک تصویر. ورودی multipart/form-data برای فایل، یا JSON/فرم برای url.

پارامتراجباریتوضیح
image*فایل تصویر (JPEG/PNG/WebP/GIF/AVIF)
url*یا آدرس عمومی http(s) تصویر
qualityخیر۱ تا ۱۰۰ — پیش‌فرض ۸۲
formatخیرoriginal (پیش‌فرض)، jpeg، png، webp، avif
max_width / max_heightخیرحداکثر ابعاد به پیکسل؛ فقط کوچک می‌کند و نسبت حفظ می‌شود
keep_metadataخیرtrue برای حفظ EXIF (پیش‌فرض حذف؛ پروفایل رنگ حفظ می‌شود)
responseخیرjson (پیش‌فرض) یا binary

* یکی از image یا url الزامی است.

پاسخ JSON

{ "ok": true, "data": {
  "id": 1024, "status": "ok",
  "input":  { "format": "jpeg", "bytes": 482113 },
  "output": { "format": "webp", "mime": "image/webp", "bytes": 98314, "width": 1600, "height": 1067 },
  "saved_bytes": 383799, "saved_percent": 79.61,
  "charged": 50, "charge_source": "wallet", "balance": 99950,
  "download_url": "https://seraf.ir/api/v1/download/AbC123...",
  "expires_at": "2026-10-30T10:10:00+00:00" } }

پاسخ باینری (response=binary)

بدنه خودِ تصویر است و آمار در هدرها — توصیه‌شده برای افزونه‌ها و پردازش انبوه:

Content-Type:          image/webp
X-Seraf-Status:        ok | skipped
X-Seraf-Input-Bytes:   482113
X-Seraf-Output-Bytes:  98314
X-Seraf-Output-Format: webp
X-Seraf-Width:         1600
X-Seraf-Height:        1067
X-Seraf-Charged:       50
X-Seraf-Balance:       99950
statusمعنی
okتصویر کوچک‌تر، تبدیل یا تغییر اندازه داده شد
skippedاز قبل بهینه بود؛ همان فایل اصلی برمی‌گردد و هزینه‌ای ندارد
توکن محرمانه/v1/download/{token}GET

دریافت فایل در حالت JSON. لینک یک‌بارمصرف است و حداکثر ۱۰ دقیقه اعتبار دارد؛ پس از اولین دانلود فایل از سرور حذف می‌شود و درخواست دوباره 404 می‌گیرد.

عمومی/v1/guest/optimizePOST

بهینه‌ساز رایگان صفحهٔ اصلی برای کاربران مهمان؛ برای استفادهٔ برنامه‌نویسی از /v1/optimize استفاده کنید.

  • ورودی: image به‌همراه quality، format، max_width
  • هدر اختیاری X-Seraf-Guest: شناسهٔ تصادفی مرورگر
  • سقف: ۵ مگابایت برای هر فایل، ۱۰۰ تصویر در ساعت برای هر مرورگر (هر IP تا ۱۰ برابر)
  • پاسخ: باینری با هدرهای X-Seraf-*؛ عبور از سقف: 429 guest_limit

نمونه‌کد

# JSON + download link
curl -X POST https://seraf.ir/api/v1/optimize \
  -H "Authorization: Bearer $SERAF_KEY" \
  -F "image=@photo.jpg" -F "quality=80" -F "format=webp"

# binary: save the optimized file directly
curl -X POST https://seraf.ir/api/v1/optimize \
  -H "Authorization: Bearer $SERAF_KEY" \
  -F "image=@photo.png" -F "response=binary" -D headers.txt -o photo.min.png

# by URL
curl -X POST https://seraf.ir/api/v1/optimize \
  -H "Authorization: Bearer $SERAF_KEY" -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/banner.jpg","format":"avif","max_width":1920}'
$ch = curl_init('https://seraf.ir/api/v1/optimize');
curl_setopt_array($ch, [
    CURLOPT_POST           => true,
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER     => ['Authorization: Bearer ' . getenv('SERAF_KEY')],
    CURLOPT_POSTFIELDS     => [
        'image'    => new CURLFile('photo.jpg'),
        'quality'  => 80,
        'response' => 'binary',
    ],
]);
$body = curl_exec($ch);
if (curl_getinfo($ch, CURLINFO_RESPONSE_CODE) === 200) {
    file_put_contents('photo.min.jpg', $body);
} else {
    $err = json_decode($body, true)['error'];
    echo $err['code'] . ': ' . $err['message'];
}
import fs from 'node:fs';
const form = new FormData();
form.append('image', new Blob([fs.readFileSync('photo.png')]), 'photo.png');
form.append('format', 'webp');
const res = await fetch('https://seraf.ir/api/v1/optimize', {
  method: 'POST', body: form,

if (!json.ok) throw new Error(json.error.code);

import os, time, requests

def optimize(path, **opts):
    while True:
        with open(path, 'rb') as f:
            r = requests.post('https://seraf.ir/api/v1/optimize',
                headers={'Authorization': 'Bearer ' + os.environ['SERAF_KEY']},
                files={'image': f}, data={**opts, 'response': 'binary'})
        if r.status_code in (429, 503):          # honour Retry-After
            time.sleep(int(r.headers.get('Retry-After', 5)))
            continue
        r.raise_for_status()
        return r.content, r.headers

data, headers = optimize('photo.jpg', quality=80, format='webp')
open('photo.webp', 'wb').write(data)

افزونهٔ وردپرس

دانلود از پنل سراف ← افزونه وردپرس (پس از ورود).

  1. افزونه را نصب و فعال کنید.
  2. در «رسانه ← بهینه‌ساز سراف ← تنظیمات» کلید API را وارد کنید.
  3. آپلودهای جدید خودکار در صف قرار می‌گیرند؛ کتابخانهٔ فعلی را با «بهینه‌سازی گروهی» پردازش کنید.
افزونه هیچ موتور فشرده‌سازی‌ای ندارد. هر فایل (تصویر اصلی و هر اندازهٔ بندانگشتی) جداگانه و پشت سر هم با کلید شما به POST /v1/optimize با response=binary فرستاده می‌شود، روی سرور سراف پردازش و مستقیم به سایت شما برگردانده می‌شود. بین درخواست‌ها مکث قابل تنظیم وجود دارد، Retry-After رعایت می‌شود و با خطای ۴۰۲ فرایند متوقف می‌شود.

حریم خصوصی و نگهداری فایل‌ها

  • حالت binary و نسخهٔ رایگان: هیچ فایلی روی سرور نمی‌ماند؛ ورودی پس از پایان درخواست و خروجی بلافاصله پس از ارسال حذف می‌شود.
  • حالت json: خروجی فقط تا اولین دانلود (حداکثر ۱۰ دقیقه) نگهداری و سپس حذف می‌شود.
  • برای گزارش مصرف فقط نام فایل، حجم‌ها، فرمت و زمان ثبت می‌شود.

توصیه‌ها

  • تصاویر را یکی‌یکی (یا با همزمانی کم) بفرستید.
  • همیشه به ۴۲۹ و ۵۰۳ با صبر به اندازهٔ Retry-After پاسخ دهید.
  • برای وب، format=webp با quality بین ۷۵ تا ۸۵ تعادل خوبی است؛ AVIF حجم کمتری دارد ولی کندتر است.
  • max_width=2560 حجم عکس‌های دوربین و موبایل را بسیار کم می‌کند.
  • پیش از پردازش انبوه، موجودی را با GET /v1/account بررسی کنید.
